    Command Name

    Title

    financials recurrence — the recurring rules' command surface

    Summary

    One subcommand group covering every act on recurring rules — reviewing the rule book (list), creating (add, detect --take), and managing (pause, resume, remove, edit) — where detection reviews proposals and add stores a rule.

    Description

    The command group the bookkeeper speaks to the planner with. Bare recurrence (or recurrence list) shows the rule book: each rule with its pattern, active status and next three projected dates, plus a footer explaining superseding. recurrence add creates a rule — flags for every field (the non-interactive route) or missing values prompted (the interactive route, same questions as the proposal editor). recurrence detect \[--min N\] runs the detector over the committed history and prints candidate rules; recurrence detect --take N adopts proposal N through the seeded editor. recurrence pause/resume/remove <prefix> toggles or deletes a rule (remove with typed 'ja'), and recurrence edit <prefix> (or --occurrence <id>) reopens the seeded editor on a rule or a single occurrence. Every action lands through the rule store's load-modify-save path; detection alone writes nothing.
