financials edit — correct a recorded or planned entry

Program

financials

Command Name

edit

Title

financials edit — correct a recorded or planned entry

Summary

Opens the interactive editor for one entry — a committed transaction (t####, full id or prefix) or a planned entry (e####) — prompting all four fields pre-filled so only what changed is applied.

Description

edit — correct a recorded transaction or a planned entry.

Run with an id from the list view ('financials list') to edit that one entry, or bare to pick from the last ten actual rows. The editor shows the current row first and then asks for date, description, category and amount in one pass — pressing Enter keeps each current value. For a committed row the finished correction is journaled as a full replacement; the console line reports the updated entry together with the new checking and savings balances. Editing a committed row to a future date instead moves it out of the committed ledger into the planned-entry register (date, description, category and amount carried over). For a planned entry, an edit toward today or the past confirms the entry into the ledger as it now stands; an edit that keeps it in the future rewrites the plan where it sits. Ids that belong to a group or a recurring-entry instance are handed to their own editors (group editor, occurrence editor).
