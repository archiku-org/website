    A cleanup change-set never adds rows to the actual books

    Title

    A cleanup change-set never adds rows to the actual books

    Non-Goal Statement

    The whole-row action set a cleanup file may use contains only removal of recorded rows, clearing of parked plans and parking of new planned entries — no action introduces a new row into the actual books.

    Summary

    Cleanup is subtractive or corrective; new recorded movements enter the books only through the ordinary entry flows, never via a fix file.

    Description

    A fix file can correct a row's fields or strike a row, and it can park a planned entry into the expected register (also a route for the interactive flows' internal ops list). It cannot create a new recorded transaction: no row-adding action exists in the change-set vocabulary, and the row engine refuses any action name outside its set. The boundary keeps cleanup files from becoming a second entry path — recorded history grows only at the entry interface, while cleanup only fixes or trims it.
