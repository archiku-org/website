Nothing is stored without passing the house checks

Title

Nothing is stored without passing the house checks

Rule Statement

A movement is refused with a stated reason unless it has a valid date, a non-empty description, an approved category and a non-zero amount.

Summary

The shared validation produces a plain-language refusal for each failure — invalid date, empty description, unapproved category, zero amount — and nothing is stored until every one passes.

Description

Every capture — typed, phrased or asked — must clear the same four checks before it can be written. The date has to be a real calendar date. The description may not be blank. The category must be approved. The amount may not be zero, because a zero movement is not a movement.

When a check fails, the owner sees exactly which one did — the entry is refused with a specific message and nothing is stored. The interactive amount question enforces the same non-zero policy while asking, replying to an invalid amount with the same explanation and giving up the entry rather than storing a guess.

# src/financials/entry.py — lines 63–91
def _validate(
  iso_date: str,
  description: str,
  category: str,
  amount: float,
  ledger: Ledger,
) -> str:
  """Validation shared by the flagged and prompted paths. Returns an
  error string, empty when the entry may proceed."""
  try:
    date.fromisoformat(iso_date)
  except ValueError:
    return f"ongeldige datum: {iso_date!r}"
  if not description.strip():
    return "omschrijving mag niet leeg zijn"
  if category not in approved_categories():
    return f"categorie {category!r} is niet in de goedgekeurde lijst"
  if amount == 0:
    return "bedrag 0 is niet toegelaten"
  if iso_date > date.today().isoformat():
    return (
      "datum ligt in de toekomst — future entries horen in het expected-register: "
      "gebruik 'financials expect'"
    )
  if ledger.transactions:
    parent, _idx = ledger.find_parent(iso_date)
    if parent is None:
      return "geen voorgaande rij gevonden voor deze datum; kan balansen niet doorzetten"
  return ""

def _validate_amount(text: str) -> float | None:
  try:
    amount = round(float(text.replace(",", ".")), 2)
  except ValueError:
    return None
  return amount if amount != 0 else None
