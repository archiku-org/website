A removal carried by a reviewed change-set must match the victim exactly

Title

A removal carried by a reviewed change-set must match the victim exactly

Rule Statement

A whole-row removal in a change-set records the victim row's exact content at removal time; when the live row no longer matches that recorded content, the removal is refused.

Summary

Row-removal fixes guard against stale reviews: the file's snapshot of the row is checked against the live row before the removal lands.

Description

A whole-row removal fix carries the row's full content as the reviewer captured it when writing the file. When the tool applies it, that captured content is checked against the live row; any drift — a field edited since the file was written, or the row already changed by another fix — refuses the removal loudly instead of deleting content the reviewer did not see. This is the same protection the interactive removal flow uses, arriving here through an offline file.
