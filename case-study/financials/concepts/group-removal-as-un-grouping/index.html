Group removal as un-grouping

Name

un-grouping

Title

Group removal as un-grouping

Summary

Removing a group statement that only dissolves the bond between member rows — the members themselves stay, which is why the command's promise is "un-group, not delete".

Description

A group in this system is a labelling bond, not an owner of its members. The concept "un-grouping" names the deliberate consequence: when a group id is removed, the only thing that disappears is the grouping statement itself — the shared label and the tie it expressed. Each member entry continues to exist independently, exactly as before the group was formed. The term keeps businesses and implementers from conflating two very different destructive acts: dissolving an association (cheap, safe, reversible by re-grouping) versus deleting the underlying entries (audited, balance-rewriting, real).

def delete_group(group_id: str) -> int:
  """Delete the group; members survive untouched (un-group, not delete)."""
  group = _resolve_group(group_id)
  if group is None:
    return 2
  from rich.prompt import Confirm

  if not Confirm.ask(f"Groep {group.id} ({group.label}) verwijderen?", default=False):
    console.print("[dim]Geannuleerd — niets gewijzigd.[/dim]")
    return 2
  groups = load_groups()
  save_groups([g for g in groups if g.id != group.id])
  console.print(f"[green]Groep verwijderd: {group.id} — leden blijven bestaan.[/green]")
  return 0
